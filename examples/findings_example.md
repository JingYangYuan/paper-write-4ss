# 研究发现写作示例：可选结构、常见失败与示范段落

本文件提供可选的论证结构，不规定固定分节、字数或句式。分几节、每节几段、材料与阐释各占多少篇幅，由论证需要决定。表达规则见 `resources/style_gate.md`，此处只引编号。

## 一、每个分析单元要回答的三个问题

三个问题缺一即视为分析未完成。可以三段分别完成，也可以一段内完成；前者易读，后者紧凑，取决于材料的信息密度。

| 问题 | 合格判据 | 回查条目 |
|---|---|---|
| 这一段证据支持什么判断 | 判断能落到具体材料上，不是"结果符合预期" | [E2] |
| 这个判断与既有解释是什么关系 | 说清是印证、限定、还是反驳，并指明对象 | [E2] |
| 它因此可以被叫作什么 | 给出概念、机制或类型命名，命名在后文保持一致 | [E2] |

条目对应 `chapters/ch07-organizing-materials.md`，用于回查段落承担的论证动作，不构成篇幅与句式要求。

## 二、可选的组织方式

| 方式 | 适用情形 | 风险 |
|---|---|---|
| 按分析框架的维度递进 | 有明确的分析框架，各维度可独立成节 | 维度并列而无递进时，读者不知道读到第三节为何还要读 |
| 按时间阶段推进 | 过程性材料、制度变迁、职业生涯 | 容易写成事件流水账，阶段命名替代了机制解释 |
| 按类型并置 | 材料呈现为几种稳定的行为模式 | 类型学做完就停，类型间关系与转化条件缺失 |
| 按张力展开 | 同一种机制既产生效果又产生反效果 | 张力被写成"有利有弊"的套话 |
| 一体化写法 | 一段之内完成证据、判断与命名 | 材料密度过高时读者跟不上，需要更长的引导句 |

上述方式可以合成：例如先按阶段推进，每一阶段内部按三个问题展开。选择哪一种，取决于材料本身呈现的秩序，而不是取决于哪种排布更整齐。

## 三、常见失败

| 失败 | 症状 | 改法 |
|---|---|---|
| 以表代文 | 报完回归表、贴完访谈，没有判断 | 每处材料后补一句"这说明什么"，并说清与既有解释的关系 |
| 材料装饰 | 删去材料后论断仍成立，说明材料只作点缀 | 换成能支撑判断的材料，或删掉该处材料 |
| 复读表格 | 逐格复述系数与显著性，读者无法看出重点 | 正文报告方向与层级，参数入表；只有需要比较效应量或解释边际效应时才引具体值（`exp-param-01`） |
| 判断悬空 | 出现"反映出深层逻辑""具有重要影响"一类无对象的判断 | 补出对象、机制与条件，或删除 |
| 分节无递进 | 三节之间是并列关系，却用了"进一步""在此基础上" | 要么改成真正的递进，要么承认并列并去掉伪递进标记 |
| 材料越界 | 访谈引文被用来支持说话人并未主张的判断 | 回到原始材料核对，越界部分移入待核验清单（`exp-cite-01`） |

## 四、示范段落

以下是一个量化分析单元，一段之内完成三个问题，材料与判断结合，可直接参照其推进方式：

> 表2报告了计时规则在四类订单上的执行差异。预约单给定的配送时长平均比即时单长十一分钟，骑手在预约单上的超时率却更高。这一反差说明平台给出的时间不是单纯的劳动定额，而是平台、商家与写字楼物业共同议定的可执行窗口：预约单宽裕出来的时长被商家备餐的不确定吸收，骑手实际拿到的余量并不比即时单多。既有研究把超时读作骑手时间管理的失败，本节的证据则指向规则本身的分配不均。据此可以把这一机制称为"余量转移"：时间压力没有消失，只是被转移到链条上议价能力最弱的一环。

质性材料的三问写法可以更短，例如：

> 十一个驿站中有九个把扫码安排在离开老人家门之后，只有两个要求当面扫码。这九个驿站的护理员普遍把多坐的五分钟说成"陪老人说两句话"，而两个当面扫码的驿站里，护理员几乎不提这件事。可见缝隙的大小不取决于护理员个体，而取决于记录发生的时点。这一发现限定了"算法控制必然压缩劳动自主性"的判断：控制强度不变，时点移动即可让自主性出现。

两段都不含固定句式可抄；可抄的是动作顺序：先给材料，再给反差，再落到判断与命名。

## 五、交付前检查

- 每个分析单元是否三问齐全？缺哪一问？
- 分节之间是真递进还是伪递进？
- 材料与阐释的比例是否服务于论证？（判断方法是删去材料看论断是否还成立，不设比例配额）
- 引文前后的语境与分析是否交代？（`exp-quote-frame-01`）
- 表格与图是否自足：不看正文能否读懂？
- 是否出现变量名、问卷模块名与行内编码规则？（`exp-var-01`）
