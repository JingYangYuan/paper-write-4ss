# 结论与讨论写作示例：可选结构、常见失败与示范段落

本文件提供可选的论证结构，不规定固定分节、字数或句式。结论的体量以能否完成四件事为准，不以占全文百分比计量。表达规则见 `resources/style_gate.md`，此处只引编号。

## 一、结论要完成的四件事

顺序自定，可以四段，也可以两段合成。四件事都做到，篇幅自然够；只做到"总结三点"而写满一页，仍然不合格。

| 事项 | 合格判据 | 回查条目 |
|---|---|---|
| 本文发现了什么 | 有层次，不重复摘要；每项发现带对象与条件 | [C1] |
| 这些发现的边界在哪 | 说清适用范围与失效条件，不是"由于数据限制"一句了事 | [C2][C3] |
| 哪些问题本文没有回答，为什么 | 未答之处由本文的设计或材料限定推出，不是泛泛"研究不足" | [C4][C5] |
| 从这些未答之处可以继续做什么 | 方向须由本文发现推出，不是另起新题 | [C6] |

第三、四件事合起来取代"研究不足"的陈套。最后一段不得停在限制上（`exp-concl-end-01`）。

## 二、两种范式的侧重

| 维度 | 社会学研究范式 | 管理世界案例范式 |
|---|---|---|
| 总结重点 | 分层呈现发现，保留条件与边界 | 提炼机制与模型的理论含义 |
| 延展方向 | 学术延展：与其他领域、时期、国家比较 | 实践延展：政策含义、管理启示 |
| 可选加段 | 视角独特性 [C3]、遗留问题 [C4] | 实践启示（须由研究发现推出） |
| 篇幅 | 以完成四件事为度，不设比例 | 同左 |

## 三、常见失败

| 失败 | 症状 | 改法 |
|---|---|---|
| 复述摘要 | 结论与摘要几乎逐句对应 | 只保留摘要装不下的内容：分层发现、边界、未答之处 |
| 空泛限制 | "本文存在诸多不足""受数据所限" | 说出具体限制，并说明它妨碍了哪一项判断 |
| 以限制收尾 | 最后一段停在"本文亦有不足" | 把限制改写为下一步的问题，或用研究议程收束（`exp-concl-end-01`） |
| 突然升维 | 结论引入前文从未出现的理论 | 升维只能沿正文已有的概念链推进 |
| 结论引入新材料 | 忽然引用新的访谈或文献 | 新材料应回到分析部分，结论只处理已有发现 |
| 政策建议清单 | 三条建议与发现无对应关系 | 每条启示回指某一项发现，删去无法回指的部分 |
| 宣称过度 | "本研究填补了空白""具有里程碑意义" | 改为对具体判断的推进，说明推进了哪一步（`exp-novelty-01`） |

## 四、示范段落

以下是一段结论开头，完成"发现什么"与"边界在哪"两件事，不含模板句：

> 本文追踪了计时规则在配送劳动中的落地过程。规则并未均匀地压低每一个骑手的时间，它先压低的是链条上议价能力最弱的一环：商家备餐、物业门禁、电梯等候的时长被逐段压缩，最终以"余量转移"的方式落到骑手身上。因此这项研究的结论有明确边界：它解释的是平台、商家与末端劳动者三方议价结构下的时间分配，不适用于平台自营配送或骑手可自主议价的场景。在同一城市的自营站点，同样的计时规则并未产生可比的超时率。

紧接着的一段可以处理未答之处与后续方向：

> 本文没有回答的是，余量转移为什么在某些城市没有出现。本文的设计只在两个城市取样，样本内的差异不足以支持城市层面的比较；而社区治理结构、写字楼管理强度与地方劳动监察频率都可能参与其中。把这三个条件纳入比较，是下一步能够做、也值得做的事。

两段的共同点：判断带对象，边界带条件，未答之处由设计推出，结尾指向可以继续的方向而非限制本身。

## 五、交付前检查

- 四件事是否齐全？缺哪一件？
- 分层的发现是否带有对象与条件，而非"具有重要影响"？
- 每项限制是否说明了它妨碍哪一项判断？
- 最后一段是否停在限制上？
- 后续方向是否由本文发现推出？
- 是否出现了"首次""填补空白"一类宣称？（`exp-novelty-01`）
