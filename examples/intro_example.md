# 引言写作示例：可选结构、常见失败与示范段落

本文件提供可选的论证结构，不规定固定分节、字数或句式。字数按目标期刊稿约与全文比例确定，本文件不给区间。表达规则见 `resources/style_gate.md`，此处只引编号，不复制条文。

## 一、引言必须完成的五个动作

段落数与顺序自定。一个动作可以写一段，也可以三段合成一段；反过来，一段里塞进三个动作也不算多。判据是动作齐全，不是段落数对。

| 动作 | 合格判据 | 回查条目 |
|---|---|---|
| 给出一个可验证的现象、数据或理论争议 | 读者三句内知道本文谈什么；首句有实质陈述，不是"随着……的广泛运用"式背景铺陈 | [I1] |
| 指出既有研究在何处失效 | 失效落在具体维度、对象或条件上，不是"研究较少""关注不足" | [I2] |
| 说明本文切入角度及选择理由 | 角度与失效处对应；理由是学术的（为什么这个角度能看到别处看不到的东西），不是"资料可得" | [I3][I4] |
| 陈述本文推进了什么 | 可在后文逐项兑现；不出现"首次""填补空白" | [I5] |
| 交代材料、方法与分析路径 | 对象、材料、方法齐全；不以"本文结构如下"代替 | [I6][I7] |

上表的标注对应 `chapters/ch03-genesis-question.md`，用于回查某一段承担了什么论证动作。标注不进正文，也不构成篇幅与句式要求。

## 二、两种常见排布（可选）

### 学术现象起手

以学术争议或概念误用开篇，先立起一个可争论的靶子，再说明既有解释为何不够。适合问题意识已经清晰、文献脉络可辨的题目，也适合理论性与方法论论文。风险是容易写成文献综述的压缩版，读者到第四段仍不知本文研究什么。

### 现实悖论起手

以一个反常事实开篇：政策预期与执行结果不符、同一制度下出现两类相反的行为、统计数据与经验观察相左。适合案例研究与政策研究。风险是悖论造得漂亮而解释跟不上，第二段之后又回到常规综述。

两种排布可以混用，例如以悖论起手、以学术争议承接。混用时须注意：读者第一次被告知本文要研究什么，不应晚于全文前四分之一。

## 三、常见失败

| 失败 | 症状 | 改法 |
|---|---|---|
| 背景铺陈过长 | 前三段都是产业趋势、政策文件与"重要议题"判断，没有可争论的陈述 | 把最有张力的那句事实提到第一段，背景压缩为一句 |
| 缺口空转 | "既有研究较少关注""尚缺乏系统考察"，说不出少在哪、缺了会怎样 | 把缺口写到维度、对象或条件上，并说明这个缺口妨碍了哪一项判断 |
| 贡献与正文不符 | 引言许诺三点贡献，正文只兑现一点 | 按正文实际推进的内容重写贡献段，宁可少说 |
| 材料交代缺席 | 只说"本文使用访谈资料"，不说谁、何时、如何进入、如何分析 | 补齐对象、时间、来源与分析方法，细节可入脚注 |
| 自我推销过度 | "本研究具有重要的理论意义与现实意义" | 删掉评价性套话，换成"本文因此能够回答……" |

## 四、示范段落

以下是一段质性研究的引言开头，动作齐全而句子自定，可直接参照其节奏，不必套用其句式：

> 自2019年起，某市社区养老驿站的护理员被要求用手机扫码记录每一次上门服务，记录本是为了结算工时。2022年的田野里我看到的却是另一番用法：护理员把扫码当成一次短暂的歇脚，在老人家里多坐五分钟，扫码之前先把水喝完。记录系统把服务切成可计价的最小单位，护理员则在单位之间寻找可以不做事的缝隙。本文把这种缝隙称为"计时之外"，并试图说明它有制度成因，同时是照护劳动得以持续的日常条件。以下分析基于两个街道、十一个驿站、四十七次随行观察与三十一次访谈，先描述扫码规则如何落地，再说明护理员如何在规则内部开辟时间。

这一段兑现了五个动作：可验证的现象（扫码记录）、失效（既有研究把这类缝隙读作控制漏洞）、切入角度与理由（把缝隙当作劳动条件而非漏洞，因为观察到的用法是主动的）、推进（提出"计时之外"）、材料与方法。它也可以写成五段，或者压缩成三段；动作不变。

模板化写法与清单式写法的逐句对照见 `contrasts_example.md`。

## 五、交付前检查

- 五个动作是否齐全？缺哪一个，缺的部分由什么替代？
- 首段有没有一句可以被引用、被反驳的实质陈述？
- 缺口是否具体到维度、对象或条件？
- 每个贡献能否在后文找到对应段落？
- 材料、方法、分析路径是否交代到读者能判断可信度的程度？
- 是否有"首次""填补空白""具有重要意义"一类无法兑现的宣称？（`exp-novelty-01`）
