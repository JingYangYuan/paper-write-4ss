# Handoff Checklists（阶段交接清单）

每次阶段交接除填写技术交接项外，须同步更新 `paper-workspace/_index/handoff-status.md` 与 `paper-workspace/_index/paper-roadmap.md`。交接记录须包含「推荐下一步」与「暂缓事项（避免过早跳步）」。

## `design` -> `lit`

**交接内容**：
- 研究主题与核心研究问题；
- 已确认的工作模式、研究取向、混合关系（如适用）及 `analysis_required` 取值；
- 学科路由与理论锚点；
- 候选研究问题（RQ）与首选研究问题；
- 初步数据或材料设想、论证用途及不得声称的内容；
- 建议检索关键词、目标领域及目标期刊；
- 阶段质量分（Rubric）、阻断项与不可声称清单。

**路径说明**：
- **推荐下一步**：开展文献定位，通过文献谱系核实选题空白与理论承接关系。
- **暂缓事项**：在文献空白尚未核实前，不要急于撰写全文或固化模型设定。

## `lit` -> `outline`

**交接内容**：
- 文献地图；
- 研究空白表；
- 理论框架与机制链；
- 研究假设或研究问题；
- 核心文献清单与证据强度评估；
- 综述论证蓝图、`claim_id` 与 `paper_id` 映射表、已核验原文位置及未核验缺口；
- 结构要求：`outline` 阶段须将结构细化至段落级写作蓝图，不得仅停留在章节标题；
- 阶段质量分、阻断项与不可声称清单。

**路径说明**：
- **推荐下一步**：将文献空白、机制链与核心证据转化为论文结构与证据映射。
- **暂缓事项**：在各章节论证功能尚未固定前，不要提前进行局部语言润色。

## `lit` -> `write`（文献综述成稿）

**交接内容**：
- `paper-registry.csv`、`review-evidence.csv`、`review-outline.md` 与 `review-gaps.md`；
- 研究问题、目标期刊、字数与结构要求及既有综述草稿（如有）；
- 需保留、修改、移除或补证的 `claim` 清单，以及明确禁止写入正文的内容；
- 输出唯一路径：`paper-workspace/05-writing/literature-review.md`；
- 成稿回查要求：所有关键判断、争议、方法批评与效应数值均须能回查至 `claim_id` 与原文位置。

## `outline` -> `analysis`

**交接内容**：
- 论文目的、结构类型及最新设计报告是否注明 `analysis_required: true`（纯理论路径通常不进入 `analysis`）；
- 研究问题与假设；
- 段落级写作蓝图路径，以及「可写段落」与「暂不写入段落」清单；
- 所需变量、数据、访谈或文本材料清单；
- 证据缺口与待补充材料；
- 经验章节预期表图或质性主题清单；
- 阶段质量分、阻断项与不可声称清单。

**路径说明**：
- **推荐下一步**：进入分析或材料验证阶段，核实数据、模型或文本材料能否支撑大纲论点。
- **暂缓事项**：证据缺口未补齐前，不要提前生成投稿正文，以免反复返工。

## `analysis` -> `write`

**交接内容**：
- 分析脚本路径与 `script-index.md`；
- 数据来源与样本口径说明；
- 模型设定或质性编码决策记录；
- 输出表格（CSV）、图形及结果摘要；
- 可写入正文的定性表述、表图占位与结果声称边界；
- Guard 审计状态、阶段质量分、阻断项及不得声称的结论清单。

**路径说明**：
- **推荐下一步**：将已验证的结果、边界条件与限制移交写作阶段，优先起草证据最充分的章节。
- **暂缓事项**：不得超出已有分析结果进行外推或扩大理论声称。

## `write` -> `check`

**交接内容**：
- 最新正文净稿路径：`manuscript.md`、`manuscript-[slug]-[date].md` 或 `revisions/styled-[slug]-[date].md`；
- 正文格式合规状态、扫描报告、修订记录及内部 source map（仅作追溯，不用于投稿）；
- 研究问题、证据边界、待核验引文清单与目标期刊信息。

**路径说明**：
- **推荐下一步**：交由 `check` 综合复核选题、摘要、论证闭环、学术诚信与技术规范，避免将实质性缺口带入投稿阶段。
- **暂缓事项**：核心论证与证据未通过复核前，不要先行导出投稿 Word。

## `check` -> `submission`

**交接内容**：
- `paper-check-report-*`、`paper-check-matrix-*`、`paper-check-revision-list-*` 及总体审稿结论；
- 阻断项处置记录、待核验引文处理状态、已改项复核证据及仍需退回修改的问题；
- 目标期刊公开投稿要求、Word 模板、GB/T 7714 或 APA 等引用体例及参考文献缺口清单。

**路径说明**：
- **推荐下一步**：仅当总体审稿结论允许时进入投稿整备，核对期刊硬性格式与投稿附件完整性。
- **暂缓事项**：不得试图用排版或 Word 模板掩盖未解决的论证、事实或诚信问题。
