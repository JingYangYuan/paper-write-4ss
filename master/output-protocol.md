# Output Protocol

本协议定义 `paper-master-4ss` 的统一输出模式。总控、模块主流程、phase、agent 原始意见、agent synthesis、最终回复和所有落盘 `.md` 报告都必须遵守。用户层导航同时遵守 `master/user-journey.md`。

## 1. 默认语言

- 所有面向用户的回复、过程日志摘要、正式报告、顾问意见和综合文件默认使用中文。
- 文献题名、作者名、期刊名、变量名、模型名、引用体例、软件命令、代码、文件路径和专有缩写可保留原文。
- 若输出包含英文术语，优先使用“中文术语（英文原文）”的首次标注方式；后续使用中文术语。

## 2. 输出类型

- 过程报告 Markdown：模块报告、流程日志、顾问意见、agent synthesis、证据表、缺口表、扫描报告和最终回复使用 Markdown 标题、列表、表格、引用和 fenced code block。
- 论文正文净稿：`paper-workspace/05-writing/manuscript*.md`、`paper-workspace/05-writing/revisions/styled*.md` 与 `paper-workspace/05-writing/literature-review.md` 的正文区只允许 `#`、`##`、`###`、`####` 标题层级和自然段。
- 正文净稿禁止出现 Markdown 装饰和过程痕迹：`**加粗**`、任务包、使用材料清单、未使用材料、待补证据、不可声称内容、Markdown 表格、引用块、代码块、HTML 注释、Mermaid 图示、任务清单和项目符号清单。
- 正文净稿可保留 `.md` 扩展名，作为 submission 模块导出 Word 的输入；扩展名不代表可以把正文写成项目报告或笔记格式。
- 文献综述的搜索日志、地图、证据表、论证蓝图和缺口报告必须保留在 `paper-workspace/02-literature/`，不得并入 `literature-review.md`。
- 禁止用纯文本框线或 ASCII 箭头图伪造结构图；机制、流程和链路必须使用 Mermaid。
- 普通证据表、清单、模型结果、引用缺口、变量字典和质量检查矩阵继续使用 Markdown 表格。
- 每个正式报告应在开头说明：任务目标、输入材料、输出路径、关键结论和限制。

## 3. Mermaid 强制场景

以下内容必须用 Mermaid 代码块表达：

- 机制链、因果链、理论机制、假设推导链。
- 阶段流程、模块交接、质量门控、回流路径。
- 理论嫁接、跨学科机制串联、竞争解释处理。
- 写作分段派发、agent 调度链路、agent synthesis 的采纳/分歧处理。
- 分析流程、模型识别链、稳健性/机制检验路径。
- 投稿整备、格式检查、引用检查、投稿包复核和回流链路。

## 4. Mermaid 推荐语法

- 机制/因果链：`flowchart LR`
- 多阶段流程：`flowchart TD`
- 决策门控：`flowchart TD`，使用菱形条件节点
- agent 派发/综合：`flowchart LR`

示例：

```mermaid
flowchart LR
  A[理论条件] --> B[中介机制]
  B --> C[经验结果]
  C --> D[可检验假设]
```

图示下方必须附 2-4 条中文解释：

- 说明每个关键节点对应的理论概念、材料来源或流程环节。
- 说明主路径与可能的替代路径。
- 标注当前证据缺口、风险点或需要回流的模块。

## 5. 输出落盘要求

- `agent-synthesis-[module]-[YYYY-MM-DD].md` 必须使用中文；若包含派发链、分歧处理链、跨模块风险链或回流链，必须加入 Mermaid 图示。
- 模块报告若包含机制、流程或门控，必须先给 Mermaid 图，再给表格和文字说明。
- 最终回复使用中文简要说明：执行模块、输出路径、关键结论、未解决风险和下一步建议。

## 6. 最终回复的用户导航

每次最终回复必须附一个终端友好的纯文字论文路径图，不使用 Mermaid 代码块。路径节点固定为：

```text
定位选题 -> 文献定位 -> 结构成型 -> 分析/材料验证 -> 正文写作 -> 投稿整备
```

用 `【当前】` 标记当前阶段，例如：

```text
定位选题 -> 文献定位 -> 结构成型 -> 分析/材料验证 -> 【当前】正文写作 -> 投稿整备
```

图后必须用中文给出三段式摘要：

- 当前位置：当前处于哪个论文阶段，本轮完成了什么。
- 推荐下一步：下一步先做什么，以及为什么现在做它。
- 需要用户决定：只列真正会改变路径的选择；若无关键选择，说明可按推荐路径继续。

若当前阶段不清，先根据 `_index/project-state.md`、`_index/handoff-status.md`、`_index/quality-score.json` 与已有产物推断最早阻断阶段，并在说明中标注依据。
