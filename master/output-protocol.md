# Output Protocol（输出格式规范）

本协议规定 `paper-master-4ss` 的统一输出格式，适用于总控流程、模块主流程、阶段文档、顾问意见、综合报告、最终回复及所有写入工作区的 `.md` 文件。用户层路径导航同步遵守 `master/user-journey.md`。

## 1. 默认语言与术语标注

- 面向用户的回复、过程日志摘要、正式报告、顾问意见与综合文件默认使用中文。
- 文献题名、作者名、期刊名、变量名、模型名、引文体例、软件命令、代码、文件路径及专有缩写保留原文。
- 首次出现英文学术术语时，优先采用「中文术语（英文原文）」格式标注，后续统一使用中文术语。

## 2. 输出文档分类与格式限制

### 2.1 过程与分析类文档

模块报告、流程日志、顾问意见、综合文件、证据表、缺口表、扫描报告与最终回复使用常规 Markdown（标题、列表、表格、引用块及 fenced code block）。正式报告开头须包含：任务目标、输入材料、输出路径、关键结论与限制条件。

普通证据表、检查清单、模型结果、引用缺口、变量字典与质量检查矩阵使用 Markdown 表格。禁止使用纯文本框线或 ASCII 字符绘制流程或机制图，过程内的流程与机制链路须使用 Mermaid。

### 2.2 论文正文净稿

`paper-workspace/05-writing/manuscript*.md`、`paper-workspace/05-writing/revisions/styled*.md` 与 `paper-workspace/05-writing/literature-review.md` 的正文区属于直接导出 Word 的净稿，**仅允许 `#`、`##`、`###`、`####` 标题层级与自然段**，严禁包含以下内容：
- `**加粗**`、Markdown 表格、引用块、代码块、HTML 注释、Mermaid 图、任务清单及项目符号清单；
- 任务包、使用材料清单、未使用材料、待补证据及不得声称内容等过程元信息。

文献综述的检索日志、文献地图、证据表、论证蓝图与缺口报告须保留在 `paper-workspace/02-literature/`，不得并入 `05-writing/literature-review.md`。

### 2.3 期刊发表级学术机制图

需进入论文正文的因果图、机制图与分析框架图，不得直接截图 Mermaid 或使用草图，须由 `mechanigraph` 模块生成符合 CSSCI/SSCI 出版标准的纯矢量 SVG（保存于 `paper-workspace/figures/`）及无头 Chrome 渲染的 PNG 自检图。图内默认采用白底黑字黑白线条，主概念用大号黑体，次级说明用加粗仿宋，分层可用灰阶；对称结构采用居中布局，非对称机制（含反馈回路、边界条件或时序）按语义布局；图内不含主标题与作者信息，图注由正文承担。

## 3. Mermaid 图示触发条件

纯文字可表述清晰的段落无需配图；出现以下结构复杂、需要可视化辅助核对的内容时，须使用 Mermaid 流程图：
- 机制链、因果链、理论机制与假设推导链；
- 阶段流程、模块交接、交付检查与退回路径；
- 理论嫁接、跨学科机制串联与竞争解释处理；
- 写作分段派活、顾问调度链路与 `agent-synthesis` 采纳/分歧处理；
- 分析流程、模型识别链与稳健性/机制检验路径；
- 全流程审稿、问题矩阵与跨模块退回链路。

## 4. Mermaid 语法与解释规范

按结构选择图型：
- 机制链、因果链、顾问派活与综合：`flowchart LR`
- 多阶段流程：`flowchart TD`
- 条件决策门控：`flowchart TD`（使用菱形条件节点）

示例：

```mermaid
flowchart LR
  A[理论条件] --> B[中介机制]
  B --> C[经验结果]
  C --> D[可检验假设]
```

每张 Mermaid 图下方须附 2–4 条中文解释，内容包括：
- 关键节点对应的理论概念、材料来源或流程环节；
- 主路径与可能的替代路径；
- 当前证据缺口、风险点或须退回的模块。

## 5. 输出文件特殊要求

- `agent-synthesis-[module]-[YYYY-MM-DD].md` 须使用中文；涉及派活链、分歧处理链、跨模块风险链或退回链时须包含 Mermaid 图。
- 模块报告若含机制、流程或门控逻辑，须先给出 Mermaid 图，再展开表格与文字说明。
- 最终回复须简明列出：执行模块、输出路径、关键结论、未解决风险与下一步建议。

## 6. 最终回复的终端路径导航

每次最终回复须附终端友好的纯文本路径图（不使用 Mermaid 代码块）。路径节点固定为：

```text
定位选题 -> 文献定位 -> 结构成型 -> 分析/材料验证 -> 正文写作 -> 投稿整备
```

使用 `【当前】` 标出所处阶段，示例：

```text
定位选题 -> 文献定位 -> 结构成型 -> 分析/材料验证 -> 【当前】正文写作 -> 投稿整备
```

路径图后须以三段式中文摘要说明：
- **当前位置**：当前所处论文阶段及本轮完成事项；
- **推荐下一步**：下一步优先动作及原因；
- **需要用户决定**：仅列出真正会改变路径的选择；若无关键分歧，说明可按推荐路径继续。

若当前阶段无法直接确定，须读取 `_index/project-state.md`、`_index/handoff-status.md`、`_index/quality-score.json` 及已有产物推断最早阻断阶段，用 `【当前?】` 标出并说明推断依据。
